# HR Analytics Dashboard (Power BI)

## Overview
This project presents an interactive HR Analytics Dashboard developed using Microsoft Power BI. It provides insights into workforce trends using HR data and supports data-driven decision-making.

## Features
- Employee overview
- Headcount analysis
- Employee turnover analysis
- Age group distribution
- Service years analysis
- Education level analysis
- Job role analysis
- Due for promotion analysis

## Tools Used
- Microsoft Power BI
- Microsoft Excel

## Files Included
- HR_analytics_dashboard.pbix
- HR_Analytics_Data.csv
- Employee_data.csv
- Retrenched_employees.csv
- Due_for_promotion&retrenchment.xlsx
